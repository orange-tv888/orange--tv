# Orange 隐私说明

适用范围：Orange（包名 `app.orange.tv`），本篇随版本一起更新，最后核对 `26.5.0`。

一句话：**没有账号，没有统计，没有广告，没有把任何数据卖给谁。** 应用只在需要某个功能时直接向提供该功能的服务器发请求，不经过任何中间服务器，也不把这些请求拼成用户画像。

## 一、Orange 自己不收集什么

- 不收集设备标识（IMEI、Android ID、广告 ID 一个都不读）。
- 不收集应用使用记录。安装列表只在电视本机用来画桌面，不上传。
- 没有崩溃上报、埋点、A/B 测试、推送 SDK。`app/build.gradle.kts` 的依赖里没有任何统计或广告库。
- 不要求登录，也没有云端账号。

## 二、会联网的地方（逐条）

| 功能 | 目标服务器 | 发出去什么 | 什么时候 | 能不能关 |
|---|---|---|---|---|
| 检查更新 | `ghproxy.net`、`raw.githubusercontent.com`、`cdn.jsdelivr.net`（三者依次尝试，取到即止） | 只是一个 GET 请求，读 `update/version.json`；服务器按 HTTP 常规会看到你的公网 IP | 应用启动后、打开控制中心时，间隔不小于 6 小时 | 不能单独关；不联网就不检查，不影响使用 |
| 天气 | `ipinfo.io` | GET 请求；服务器看到你的公网 IP，据此返回一个粗略的城市坐标 | 天气首次定位、以及定位过期后 | 可以把天气关掉、或手工选城市，见「设置 → 个性化 → 天气」 |
| 天气 | `api.open-meteo.com` | 上一步得到的经纬度 | 同上，以及每次刷新天气 | 同上 |
| 天气 | `geocoding-api.open-meteo.com` | 你在电视上输入的城市名 | 手工搜索城市时 | 不去搜索就不会发 |
| 壁纸 | `cn.bing.com` | GET 请求；服务器看到你的公网 IP | 选择「每日精选」壁纸时，每天一次 | 可以换成内置壁纸或自己的照片 |
| 航拍屏保 | `sylvan.apple.com` | GET 请求；服务器看到你的公网 IP | 播放航拍影片时 | 可以换成照片、本地视频或不用屏保 |
| 手机整理页 | 电视本机（`127.0.0.1` 与局域网地址上的一个端口） | 只在你自己的局域网内；手机与电视直连，不经过互联网 | 打开「用手机整理」时 | 不打开就不启动 |
| 图标库 | ~~`aerial.qust.me`~~ | **26.5.0 起已关闭，不再发出任何请求**。磁贴改用应用自己的图标 | — | 已关 |

补充：

- **没有任何请求带用户标识**：不带账号、不带设备号、不带安装 ID。除了上面写明的参数，没有附加字段。
- `ipinfo.io` 返回的是**城市级**坐标（精度到城市，不是街道），用来取当地天气；这个坐标只存在电视本机，不回传。
- 电视上的诊断信息（控制中心 → 个性化 → 反馈问题）**只在本机生成文本**，不会自动上传。要不要贴出去、贴到哪里，由你自己决定；那份文本里不含账号、IP、Wi-Fi 名称和安装的应用列表。

## 三、数据存在哪里

全部存在电视本机，随应用卸载一起删除：应用排列与文件夹、壁纸与屏保设置、天气定位与城市、上传过的照片和视频、图标选择。**没有云端备份**（`allowBackup=false`）。

## 四、权限与用途

| 权限 | 用途 |
|---|---|
| 网络 / 网络状态 | 上面那些请求 |
| `WRITE_SECURE_SETTINGS` | 只在用电脑装了「桌面守护」时由 adb 授予，用于把桌面守护和无障碍设置写回去。侧载安装的用户没有这个权限，也不影响使用 |
| 无障碍服务（Home Guard） | 接管主页键，把原桌面的主页键让给 Orange。可在电视设置里随时关掉 |
| 通知使用权 | 小米等固件待机后会杀掉第三方桌面，用它把 Orange 拉回来 |
| 使用情况访问 | 判断前台是不是原桌面，只在 Android 6 及以下需要 |
| 悬浮窗 | 开机后立刻打开 Orange |
| 读存储 / 照片 | 只读你主动用手机传过来的图片和视频 |

Orange 不申请定位权限，也不读取 GPS。（`26.5.0` 之前的构建在 `install.sh` 里会顺带授予定位权限，仅用于显示 Wi-Fi 名称；现在已去掉，代价只是不再显示 Wi-Fi 名称。）
